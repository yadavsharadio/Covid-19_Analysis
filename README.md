
# 🦠 COVID-19 Analysis & Visualisation

## 📌 Project Overview

This project presents an interactive **COVID-19 Analysis Dashboard** created using **Microsoft Power BI**.

The purpose of this project is to analyze COVID-19-related data, identify important trends and patterns, and present the findings through interactive visualizations.

The data was first cleaned and prepared using **Microsoft Excel** and then imported into **Power BI** for data modeling, analysis, and visualization.

---

## 🛠️ Tools & Technologies Used

| Tool | Purpose |
|---|---|
| **Microsoft Excel** | Data cleaning and preparation |
| **Microsoft Power BI** | Data analysis and visualization |
| **Power Query** | Data transformation |
| **Power BI Visuals** | Interactive dashboard creation |

# 🚀 How to Use This Power BI Project

## 1. Download the Project

Download or clone this repository to your computer.

You can download the repository using:

**GitHub → Code → Download ZIP**

After downloading, extract the ZIP file.

---

## 2. Install Power BI Desktop

To open the `.pbix` file, you need **Microsoft Power BI Desktop** installed on your Windows computer.

Power BI Desktop is available as a free application from Microsoft.

Official download:

[Download Power BI Desktop](https://learn.microsoft.com/en-us/power-bi/fundamentals/desktop-get-the-desktop)

Microsoft recommends using the latest version of Power BI Desktop.

---

## 3. Open the Power BI File

After installing Power BI Desktop:

1. Open **Power BI Desktop**.
2. Click **File**.
3. Select **Open**.
4. Select **Browse this device**.
5. Navigate to the downloaded project folder.
6. Select:

```text
COVID-19 Analysis.pbix
```

7. Click **Open**.

The complete Power BI report should now open in Power BI Desktop.

A `.pbix` file can contain the report pages, data model, queries, and visualizations.
